# crypto-lab-rank-metric

## What It Is

This repository is the planned S10 Crypto Lab companion for rank-metric code mathematics. The implementation will compare Hamming and rank weight on the same extension-field vectors, expand those vectors into base-field matrices, and execute one bounded Gabidulin/MRD decoding example. It will keep the mathematical code separate from historical public-key systems built around rank codes. No learner-facing implementation or deployed lesson exists on this baseline commit.

## Status

Design and primary-source review are in progress on a feature branch. See `docs/design-record.md` for the bounded model, sources, and acceptance criteria.
